## 11. Profil Saya

### 11.1 Header & Informasi Akun

- Breadcrumb Beranda → Profil.
- Card header: avatar inisial, nama, badge Aktif, jabatan — unit kerja, email, tombol Edit Profil.

![Profil — Header](/panduan/profil-header.png)

> *Gambar 22 — Card header profil dengan avatar dan tombol Edit.*

**Edit Profil:**

1. Klik Edit Profil → popup form terbuka.

   ![Tombol Edit Profil — elemen di card header](/panduan/profil-tombol-edit.png)

   > *Gambar 22a — Elemen tombol Edit Profil.*

2. Isi field: nama, username, email, no HP, unit kerja, jabatan (nama & username wajib).
3. Klik Simpan → data profil terupdate.

   ![Form Edit Profil — elemen field di popup](/panduan/profil-form-edit.png)

   > *Gambar 22b — Elemen form edit profil.*

### 11.2 Keamanan

1. **Password:**
   - Klik Ganti Password → popup → isi password baru & konfirmasi (minimal 4 karakter) → Simpan.

     ![Form Ganti Password — elemen modal](/panduan/profil-ganti-password.png)

     > *Gambar 22c — Elemen form ganti password.*

2. **Notifikasi Email:**
   - Toggle switch Notifikasi Email → toast. Deskripsi “Kirim ringkasan arsip harian”.

     ![Switch Notifikasi Email — elemen toggle](/panduan/profil-notifikasi.png)

     > *Gambar 22d — Elemen switch notifikasi.*

3. **Sesi Perangkat:**
   - Buka Kelola perangkat login → klik Keluar semua → semua sesi lain dicabut.

     ![Tombol Keluar Semua — elemen di Keamanan](/panduan/profil-keluar-semua.png)

     > *Gambar 22e — Elemen tombol Keluar semua.*

### 11.3 Tanda Tangan Digital

Card khusus jika pimpinan/staff_tu.

1. **Jika belum ada:**
   - Lihat dashed border + icon signature + “Belum ada tanda tangan” → klik Pilih Gambar Tanda Tangan.

     ![Card Belum Ada TTD — elemen placeholder](/panduan/profil-ttd-belum.png)

     > *Gambar 23a — Elemen placeholder tanda tangan.*

2. **Jika ada:**
   - Lihat preview gambar + nama file.
   - Klik Ganti atau Hapus sesuai kebutuhan.

     ![Preview TTD — elemen gambar + tombol Ganti/Hapus](/panduan/profil-ttd-preview.png)

     > *Gambar 23b — Elemen preview tanda tangan.*

3. Upload via uploader (crop/cek rasio 2:1, maks 2 MB) → simpan ke folder Tanda Tangan → toast + refresh.

![Tanda Tangan Digital](/panduan/profil-ttd.png)

> *Gambar 23 — Card Tanda Tangan Digital.*

### 11.4 Aktivitas Saya

Card kanan:

- Stats grid 3: Surat Keluar, Terarsip, Belum Diarsip, plus progress bar.
- Riwayat Terbaru: timeline icon per aksi (login, buat surat, update, hapus) + label + tanggal relatif (Hari ini/Kemarin). Jika kosong “Belum ada aktivitas.”
- Pintasan: Tombol Buat Surat Keluar (jika staff_tu) + Lihat Arsip Saya, footer “Alur simple: fokus hanya buat & arsip”.
