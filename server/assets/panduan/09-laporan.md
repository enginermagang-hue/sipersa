## 9. Laporan

> **Akses:** Laporan hanya untuk admin & staff. Pimpinan tidak melihat menu Laporan.

### 9.1 Filter & Ringkasan

Header “Laporan Persuratan & Arsip — Rekap Surat Masuk, Keluar, Arsip — Periode” + Export Excel & Cetak / PDF.

**Card filter** (periode dua field tanggal start/end, klasifikasi):

![Card Filter Laporan — elemen periode & klasifikasi](/panduan/laporan-card-filter.png)

> *Gambar 18a — Elemen card filter.*

**KPI** (4 kartu): Surat Masuk, Surat Keluar, Total Diarsipkan, Perlu Tindak Lanjut.

![Laporan — Filter & KPI](/panduan/laporan-filter.png)

> *Gambar 18 — Card filter periode & klasifikasi plus 4 KPI.*

### 9.2 Grafik

- Tren Bulanan (6–12 bulan): bar group masuk vs keluar, highlight bulan ini.
- Klasifikasi Donut: diagram lingkaran per klasifikasi, tengah “Total Surat”, legend nama + jumlah (persen).

![Laporan — Grafik](/panduan/laporan-grafik.png)

> *Gambar 19 — Grafik tren bulanan dan donut klasifikasi.*

### 9.3 Tabel & Tab

- **Tab** (Gabungan, Surat Masuk, Surat Keluar, Arsip): klik tab → reset halaman.

  ![Tab Laporan — elemen pilihan tab](/panduan/laporan-tab.png)

  > *Gambar 20a — Elemen tab.*

- **Tabel:** Kolom Jenis (badge), No. Surat, Tgl, Asal/Tujuan, Perihal, Status, Lokasi Arsip. Cari dengan field search (debounce) + reset halaman.
- **Footer:** “Menampilkan X dari Y surat • Periode” + angka halaman.

![Laporan — Tabel](/panduan/laporan-tabel.png)

> *Gambar 20 — Tabel laporan tab Gabungan dengan pencarian.*

### 9.4 Export & Cetak

1. **Export Excel:**
   - Klik Export Excel.

     ![Tombol Export Excel — elemen di header laporan](/panduan/laporan-export.png)

     > *Gambar 20b — Elemen tombol Export.*

   - File Excel dengan kop instansi otomatis terunduh. Toast sukses/gagal.
2. **Cetak / PDF:**
   - Klik Cetak / PDF → halaman print-friendly terbuka (kop + tabel) → dialog print browser.

     ![Tombol Cetak/PDF — elemen di header](/panduan/laporan-cetak.png)

     > *Gambar 20c — Elemen tombol Cetak.*
