## 13. FAQ & Bantuan

**Q: Login Google error “belum dikonfigurasi”?**
A: Login Google belum diaktifkan admin IT. Hubungi admin, atau pakai login username/password sementara.

![Pesan error Google belum dikonfigurasi — elemen toast](/panduan/faq-google-config.png)

> *Gambar FAQa — Elemen pesan error Google.*

**Q: Login Google “Akun tidak terdaftar”?**
A: Email Google Anda belum ada di daftar user. Admin harus buat user dulu di Admin → Users dengan email sama. Tidak ada buat otomatis.

**Q: Upload gagal “File terlalu besar”?**
A: Batas upload 25 MB. Kompres PDF/gambar atau pecah file. Jika masih gagal, cek token Dropbox.

![Pesan File terlalu besar — elemen toast error](/panduan/faq-file-besar.png)

> *Gambar FAQb — Elemen pesan file terlalu besar.*

**Q: File Dropbox tidak muncul / 401?**
A: Token Dropbox kadaluarsa. Gunakan refresh token yang dianjurkan. Folder tujuan: Surat Masuk, Surat Keluar, Arsip.

**Q: Surat hilang setelah hapus?**
A: Data masih tersimpan dan bisa dipulihkan. Untuk arsip, admin bisa toggle Terhapus → Restore. Untuk surat, hubungi admin.

![Toggle Terhapus — elemen untuk restore](/panduan/faq-restore.png)

> *Gambar FAQc — Elemen toggle Terhapus.*

**Q: Disposisi tidak terkirim WA?**
A: Pastikan WA aktif, token valid, no HP penerima format 62xxx, dan centang notify saat buat/teruskan.

![Toggle Notify WA — elemen centang di form disposisi](/panduan/faq-notify.png)

> *Gambar FAQd — Elemen toggle notify.*

**Q: Nomor surat tidak berurutan?**
A: Nomor otomatis per tahun + klasifikasi. Jika tahun ganti, urutan reset ke 1. Jangan ubah nomor manual.

**Q: Bagaimana ganti logo/kop?**
A: Hubungi admin IT untuk ubah logo/kop instansi via pengaturan. Pergantian akan terlihat setelah refresh.

**Q: Butuh bantuan?**
A: Di halaman Tentang → Bantuan ada tombol Lihat Profil & Kembali ke Dashboard. Hubungi admin instansi untuk reset password/Google atau pendaftaran akun.

![Card Bantuan — elemen di halaman Tentang](/panduan/faq-bantuan.png)

> *Gambar FAQe — Elemen card Bantuan.*
