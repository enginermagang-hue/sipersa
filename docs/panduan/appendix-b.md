## Appendix B — Glosarium

| Istilah | Arti |
|---------|------|
| Sifat surat | biasa (netral), segera (merah), penting (kuning), rahasia (biru) — badge di list |
| Sifat disposisi | biasa/segera/sangat_segera/rahasia — prioritas tindak lanjut |
| Status surat masuk | diterima → didisposisikan → ditindaklanjuti → selesai |
| Status surat keluar | draft → menunggu persetujuan → ditolak/terkirim → selesai |
| Status disposisi | baru (kuning) → diproses (biru) → selesai (hijau), lewat jika batas waktu < hari ini |
| Retensi | sisa tahun hitung sekarang - tgl buat → Aktif/Menjelang/Kadaluarsa |
| ID File | ID stabil file di Dropbox (bukan path) |
| Soft delete | Data tidak dihapus fisik, masih bisa dipulihkan |
| TTD digital | Tanda tangan digital di profil, folder Tanda Tangan |
| WA Fonnte | Antrian WA, jika aktif akan kirim notifikasi |
